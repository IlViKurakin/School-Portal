ПОРТАЛ ПРИКРЕПЛЕНИЯ УЧЕНИКОВ
КРАТКАЯ ИНСТРУКЦИЯ ДЛЯ РАЗВЕРТЫВАНИЯ
============================================================

1. Рекомендуемая среда
------------------------------------------------------------
Windows Server / Windows VM
Python 3.12 x64

2. Важно
------------------------------------------------------------
На сервер переносится СУЩЕСТВУЮЩИЙ portal.db.
Не создавать пустую новую базу вместо него.

Файл Доступы_портал_прикрепления.xlsx
НА СЕРВЕР НЕ КОПИРОВАТЬ.

3. Необходимые данные
------------------------------------------------------------
portal.db
uploads\
generated_documents\
templates\
все *.py файлы проекта
requirements.txt / requirements_server_additions.txt
export_template.xlsx и другие рабочие шаблоны

4. Виртуальное окружение
------------------------------------------------------------
py -3.12 -m venv venv
venv\Scripts\activate

Установить зависимости основного проекта,
а затем зависимости из:
requirements_server_additions.txt

5. Production-переменные окружения
------------------------------------------------------------
PORTAL_SECRET_KEY=<длинный случайный секрет>
PORTAL_HTTPS=1

PORTAL_SECRET_KEY должен быть постоянным
и храниться только на сервере.

6. Запуск
------------------------------------------------------------
Не использовать Flask development server
как постоянный production-запуск.

Backend:
127.0.0.1:8080

Запуск через Waitress:
venv\Scripts\waitress-serve.exe --listen=127.0.0.1:8080 app:app

7. HTTPS
------------------------------------------------------------
Перед Waitress настроить корпоративный
reverse proxy: IIS / nginx / Caddy.

Наружу публиковать только HTTPS / 443.

Пример адреса:
https://school-pa.top-academy.ru

8. OCR
------------------------------------------------------------
PaddleOCR работает локально на сервере.
Сканы документов не требуется отправлять
во внешние AI / OCR API.

Текущая рабочая среда:
PaddlePaddle 3.0.0
PaddleOCR 3.7.0

9. PDF
------------------------------------------------------------
Для серверной конвертации DOCX -> PDF
рекомендуется LibreOffice headless.

10. Резервное копирование
------------------------------------------------------------
Резервировать как единый комплект:

portal.db
uploads\
generated_documents\
templates\

11. Проверка после переноса
------------------------------------------------------------
- вход администратора;
- вход МУП;
- МУП видит только свой филиал;
- вход сотрудника аттестации;
- мультифильтр филиалов;
- создание ученика;
- загрузка PDF/JPG;
- локальное OCR;
- отправка в ПА;
- замечания и исправления;
- статус Готово к зачислению;
- Excel для Дневник.ру;
- формирование справки;
- формирование выписки;
- повторное формирование;
- МУП скачивает PDF;
- аттестация/admin скачивают PDF и DOCX.

12. Нагрузка
------------------------------------------------------------
Для пилота можно использовать текущую SQLite.

Перед массовым запуском на 76 филиалов
провести нагрузочный тест.

При значительном количестве одновременных
операций записи рассмотреть PostgreSQL.
